# Random User Generator & Google Sheet Integration

এই প্রজেক্টটি দ্বারা আপনি র্যান্ডম ইউজার তথ্য (Name, Username, Email, Password) তৈরি করতে পারবেন এবং সরাসরি Google Sheet-এ সাবমিট করতে পারবেন।

## যেভাবে ব্যবহার করবেন:
1. `index.html` ফাইলটি যেকোনো ব্রাউজারে খুলুন।
2. আপনার তৈরি করা Google Apps Script Web App URL ফিল্ডে লিংক দেওয়া রয়েছে।
3. **Generate Data** বাটনে ক্লিক করে নতুন ইউজার তৈরি করুন।
4. **Submit to Sheet** বাটনে ক্লিক করলে ডাটা অটোমেটিক আপনার Google Sheet-এ জমা হবে।
