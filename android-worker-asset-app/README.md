# Worker Asset Android App

This folder contains a simple Android app wrapper that loads the existing Worker Asset web app inside a `WebView`.

## Steps to open in Android Studio

1. Open Android Studio.
2. Choose `Open`.
3. Select the `android-worker-asset-app` folder.
4. Let Gradle sync.
5. Run the app on an emulator or real Android device.

## Notes

The app loads the HTML content from:
`app/src/main/assets/www/index.html`

To update the UI, edit that file or replace it with a newer version of the web app.
